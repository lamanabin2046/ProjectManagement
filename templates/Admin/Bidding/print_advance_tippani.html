श्रीमान प्रमुख प्रशासकिय अधिकृत ज्यू,

यस कार्यालय अन्तर्गत सञ्चालन भइरहेको {{ project.name }} योजना अन्तर्गत ठेक्का नं. {{ sealed_bid.bidding_number }} का लागि निर्माण व्यवसायी {{ sealed_bid.bidder_name_nepali }} बाट सम्झौता बमोजिम कार्य अगाडि बढाउन रु. {{ advance_payment.approved_amount|floatformat:2|to_nepali_number }}/- अग्रिम भुक्तानी स्वीकृत गरिदिनुहुन मिति {{ approval_date_nepali|nepali_date }} गते निवेदन पेश भएको छ।

सो अग्रिम भुक्तानी रकम बापत सार्वजनिक खरिद ऐन तथा नियमावली बमोजिम निर्माण व्यवसायीबाट {% if bank_guarantee %} {{ bank_guarantee.bank_name }} बाट जारी जमानत नं. {{ bank_guarantee.guarantee_number }}, रकम रु. {{ bank_guarantee.guaranteed_amount|floatformat:2|to_nepali_number }}/- बराबरको बैंक जमानत मिति {{ issue_date_nepali|nepali_date }} देखि मिति {{ expiry_date_nepali|nepali_date }} सम्म म्याद कायम हुने गरी {% else %} रीतपूर्वकको बैंक जमानत {% endif %} यस कार्यालयको नाममा पेश भई दर्ता भएको छ।

पेश भएको बैंक जमानत जाँचबुझ गर्दा सम्झौता तथा प्रचलित कानुन बमोजिम रीतपूर्वकको देखिएकोले माथि उल्लेखित रकम अग्रिम भुक्तानी स्वीकृत गरी भुक्तानी दिन उपयुक्त देखिन्छ।

तसर्थ, उक्त अग्रिम भुक्तानी स्वीकृत गर्ने सम्बन्धी निर्णयार्थ यो टिप्पणी पेश गरेको छु।
